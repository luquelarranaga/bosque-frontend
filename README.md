# Welcome to Bosque 🌳

Bosque is a custom app for a client who wants to keep track of plants in their land. This mobile app allows them to post new plants, and update their log history, description and images as and when needed. All plants will be made visible on an interactive map, which allows the client to better visualise the development of their plant growth within their land.

### **PLEASE NOTE: This project is currently a WIP.**

---

To get started, fork and clone the repo to you local device before following the below instructions:

## 1) Install dependencies

```bash
npm install
```

## 2) Run the app

```bash
npx expo start
```

Choose to run the app on:

- Android emulator
- iOS simulator
- Expo Go (physical device)
- Web (limited support)

## 3) Optional: reset starter project

Restores the starter template and moves current app logic into `app-example/`:

```bash
npm run reset-project
```
